# Heart Disease Risk Prediction

This repository presents an end-to-end Machine Learning project for predicting heart disease risk using patients' clinical and lifestyle information. The project covers the complete data science workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, predictive modeling, model evaluation, experiment tracking, and deployment through an interactive Streamlit application.

---

## Project Overview

The objective of this project is to predict whether a patient is at risk of heart disease based on demographic, lifestyle, and clinical attributes. The project follows a complete machine learning pipeline, from understanding the dataset and exploring patterns to training predictive models and deploying the final solution.

---

## Key Features

- Cleaned and preprocessed the healthcare dataset.
- Handled missing values, duplicate records, and outliers.
- Performed comprehensive Exploratory Data Analysis (EDA).
- Conducted statistical analysis to identify relationships between clinical features and heart disease risk.
- Answered healthcare analytical questions using data visualization.
- Applied feature engineering to improve model performance.
- Trained and compared multiple Machine Learning models.
- Optimized model performance using GridSearchCV.
- Tracked experiments using MLflow.
- Developed an interactive Streamlit application for real-time heart disease risk prediction.

---

## Exploratory Data Analysis

The project explored several important healthcare questions, including:

- Relationship between age and heart disease risk.
- Impact of smoking on heart disease.
- Effect of obesity and diabetes.
- Influence of family history.
- Relationship between blood pressure, cholesterol, and heart disease.
- Gender-based analysis.
- Feature importance analysis.
